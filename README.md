เว็บแอปพลิเคชันสำหรับการแจ้งซ่อมและยืมอุปกรณ์ประจำสโมสรนิสิตและหอพัก  


---

##  Problem Statement & Pain Point
- **ปัญหาเดิม:** การแจ้งซ่อมและการขอยืมอุปกรณ์กิจกรรม (ปลั๊กพ่วง, ไมค์, โปรเจกเตอร์) ใช้การจดใส่กระดาษ หรือการทักแชตส่วนตัว
- **ผลกระทบ:** ตรวจสอบประวัติยาก ข้อมูลตกหล่น ไม่สามารถติดตามสถานะการยืม-คืน หรือสถานะการแจ้งซ่อมย้อนหลังได้
- **แนวทางแก้ไข:** พัฒนา Web Application ศูนย์รวมเพื่อจัดการคำขอ แสดงสถานะแบบ Real-time และแยกสิทธิ์การใช้งานชัดเจน

---

##  Target Users & Roles
1. **Student (นิสิต):**
   - ดูรายการอุปกรณ์และสถานที่ที่มีในระบบ
   - ยื่นเรื่องแจ้งซ่อม หรือ ยืมอุปกรณ์กิจกรรม
   - ติดตามสถานะคำขอของตนเอง และยกเลิก/ลบคำขอของตนเองได้
2. **Admin (เจ้าหน้าที่):**
   - เพิ่มรายการอุปกรณ์หรือสถานที่ใหม่ลงคลัง
   - ตรวจสอบรายการคำขอทั้งหมดในระบบ
   - อัปเดตสถานะการอนุมัติ (`Pending` ➔ `Approved` ➔ `Completed`)
   - จัดการลบรายการคำขอในระบบ

---

### 1. ขอบเขตด้านการทำงาน (Functional Scope)
- **ระบบยืนยันตัวตนและการจัดการสิทธิ์ (Authentication & Authorization):**
  - รองรับการเข้าสู่ระบบแบบแบ่งบทบาท (Role-based) ระหว่าง นิสิต (`student`) และ เจ้าหน้าที่ (`admin`)
  - ใช้ Secure Session Control และการป้องกัน CSRF / XSS ในการทำธุรกรรม
- **ระบบจัดการคำขอ (Request Management - CRUD):**
  - **Create:** นิสิตสร้างคำขอแจ้งซ่อมหรือยืมอุปกรณ์ / เจ้าหน้าที่เพิ่มรายการอุปกรณ์ใหม่เข้าสู่ระบบ
  - **Read:** แสดงรายการคำขอยืมและแจ้งซ่อมพร้อมสถานะ Real-time (นิสิตเห็นเฉพาะของตนเอง / เจ้าหน้าที่เห็นทั้งหมด)
  - **Update:** เจ้าหน้าที่สามารถปรับเปลี่ยนสถานะคำขอ (`Pending` ➔ `Approved` ➔ `Completed`)
  - **Delete:** นิสิตยกเลิกคำขอของตนเองได้ / เจ้าหน้าที่สามารถลบคำขอใดก็ได้ในระบบ

### 2. ข้อจำกัดของระบบ (Out of Scope / Future Improvements)
- ยังไม่มีระบบแจ้งเตือนผ่าน Email หรือ Line Notify เมื่อสถานะคำขอมีการเปลี่ยนแปลง
- การจัดการคืนอุปกรณ์ใช้การอัปเดตสถานะเป็น `Completed` โดยยังไม่มีระบบคำนวณค่าปรับกรณีคืนสาย
